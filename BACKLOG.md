## 2026-05-07 - If-Then Protocol (Implementation Intentions Engine)
- Psych: Implementation Intentions ("If-Then" plans) are a well-researched cognitive strategy (Gollwitzer, 1999) shown to bypass executive function demands by automating task initiation through pre-committed conditional triggers. 2026 TherapyForAdulting evidence review confirms they work exceptionally well for ADHD because they offload the "when/where/how" decision from working memory at the moment of action. The trigger becomes environmental rather than volitional.
- Impl: Rust rule engine with a Tauri interface for defining If-Then pairs. Rules evaluate context (time, app focus, location, task completion events) and trigger actions (nudge overlay, auto-launch app/script, queue next task, start focus timer). Example: "If it is 9:00 AM on Monday, then open weekly planning flow." "If I open YouTube during a focus session, then show a sticky note with current task." "If Task A completes, then auto-enqueue Task B with a 2-min priming countdown." Rules stored as a lightweight SQLite-backed DSL.
- Priority: High

## 2026-05-07 - Zeigarnik Momentum Bridge
- Psych: Zeigarnik Effect — the brain creates persistent "psychic tension" around unfinished tasks, making them harder to abandon than to continue. ADHD brains struggle with *initiation*, not necessarily *continuation*. A 2-minute micro-commitment ("just open the file and read the first sentence") lowers the activation energy barrier below the procrastination threshold. Once started, the open-loop cognitive tension does the heavy lifting.
- Impl: Rust/Tauri — (1) Task Decomposer: AI breaks any task into a "2-min ignition step" (absurdly low friction). (2) Open-Loop Tracker: mark task state as "ignited" and surface persistent visual indicator (e.g. pulsing dot, progress bar at 5%). (3) Momentum Prompt: after 2 min elapsed, show a single gentle nudge — "The hardest part is done. Keep going?" with a one-tap continue. (4) Abandon Friction: if user tries to close the ignited task, require a deliberate "park it" action (not a dismiss swipe) to create a micro-pause that engages the Zeigarnik tension.
- Priority: HIGH — directly targets the #1 reported ADHD blocker (task initiation) with a psychologically grounded mechanism, not just another timer.

## 2026-05-07 - Contextual Cue Surfacing (Environmental Scaffolding Engine)
- Psych: A 2026 PMC study (Developmental Science, Apr 2026) found that contextual cue transparency — making relevant environmental cues visually explicit — significantly reduces cognitive load and improves cognitive control in children with ADHD. The mechanism: ADHD brains under-rely on internal executive function and over-rely on external, environmental cues. When cues are buried or implicit (e.g. "remember you need your notebook for this task"), working memory is taxed and task initiation stalls. Making cues transparent (e.g. visually surfacing "You'll need: notebook, pen, timer" before the task starts) offloads that demand to the environment itself. This extends the Priming Protocol by automating cue detection and surfacing, turning Kairos into a "prosthetic environment" that scaffolds attention.
- Impl: Rust/Tauri — (1) Task-Cue Mapper: when a task is created or scheduled, Kairos prompts the user to attach 1-3 contextual cues (physical items, apps, tabs, documents, or environmental states like "quiet room"). Stored as structured metadata in SQLite. (2) Pre-Task Cue Overlay: 60 seconds before a focus session begins, Kairos displays a translucent overlay listing the required cues as a visual checklist. Example: "For 'Write Essay': [x] Google Docs open [ ] Noise-cancelling headphones on [ ] Water bottle filled". (3) Smart Cue Detection: for digital cues (specific apps/tabs), Kairos checks if they're already open and auto-checks them. Physical cues remain manual taps. (4) Cue Analytics: track which cues the user consistently skips vs. uses, and surface patterns ("You focus 40% longer when you have headphones on"). Over time, Kairos suggests cue optimizations. (5) Integration with If-Then Protocol: cue states can serve as If-Then triggers (e.g. "If all cues are ready, then auto-start the timer").
- Priority: High — fills a critical gap between task planning and task execution. Existing features handle *after* you start; this handles the *environmental setup* that determines whether starting is even possible. Low implementation complexity (mostly metadata + overlay UI), high psychological leverage.

## 2026-05-07 - Attention Residue Flush Protocol (Cognitive Transition Reset)
- Psych: Sophie Leroy's attention residue theory (2009, updated 2026 GoalsAndProgress review) demonstrates that when you switch tasks, cognitive activation from the previous task lingers involuntarily — especially if it was unfinished or emotionally loaded. ADHD brains are disproportionately affected because they have weaker inhibitory control to suppress the prior task's "open loops." The 5-Minute Flush Protocol (Make10000Hours, 2026) uses structured cognitive offloading to forcibly close those loops before the next task begins. This is distinct from the existing "Bridge" (Interstitial Journaling) feature: the Bridge is reflective and logs *what happened*; the Flush is a *clearing ritual* that actively dumps residual cognitive load — unfinished sub-tasks, emotional friction, open questions — into external storage so working memory is freed. Research from arxiv 2603.17258 (Apr 2026) confirms that adults with ADHD who use structured cognitive offloading during transitions show measurable improvement in subsequent task focus duration.
- Impl: [Rust/Tauri] — (1) Flush Trigger: automatically surfaces when a focus session ends or user manually initiates a task switch. (2) 3-Step Dump Interface: Step A — "Brain Dump" text box (60s timed): user types any lingering thoughts about the task they just left. Step B — "Unfinished Capture": Kairos auto-populates any incomplete sub-tasks from the ended session into a "parking lot" list so the brain knows they're saved, not lost. Step C — "Sensory Reset": a 30-second guided breathing animation (box breathing 4-4-4-4) with optional ambient sound to create a parasympathetic bridge between cognitive contexts. (3) Residue Score: after the flush, Kairos shows a "Mental Clarity" indicator (based on time spent dumping + number of items captured) so the user gets feedback on how "clean" the transition was. (4) Analytics: track flush patterns — which task types produce the most residue? Surface insights weekly ("Tasks involving code reviews leave 3x more residue than writing tasks — consider a longer flush buffer after reviews"). Store all data in local SQLite.
- Priority: High — directly addresses the #1 hidden productivity killer for ADHD: not starting tasks, but *poor quality transitions between tasks*. Complements the existing Bridge and Zeigarnik features rather than duplicating them.

## 2026-05-07 - Attention Residue Clearing Ritual (5C Protocol)
- Psych: Gloria Mark's research (UC Irvine) shows it takes ~25 min to refocus after a task switch. ADHD brains suffer worse due to impaired "attentional inhibition" — the previous task's mental context lingers. The 5C Protocol (Capture → Close → Clear → Cue → Commit) is a structured 90-second transition ritual that systematically drains attention residue. "Capture" offloads open loops to external storage; "Close" provides psychological completion; "Clear" resets sensory environment; "Cue" primes the next task's context; "Commit" triggers intentional initiation. After ~2 weeks of repetition, the brain learns the pattern and task-switching becomes semi-automatic (classical conditioning on the ritual sequence).
- Impl: [Rust/Tauri] A "Transition Bridge" modal that appears between task blocks. Steps: (1) Capture: quick-text input to dump leftover thoughts into a "parking lot" note. (2) Close: animated checkmark + brief summary of completed work. (3) Clear: 15-second breathing/visual reset animation (screen dims, minimal UI). (4) Cue: show next task title + first micro-step. (5) Commit: single "Go" button that starts the next task timer. All steps are skippable but tracked — the app learns which steps the user tends to skip (insight data). Local Rust sidecar handles timer logic and ritual state machine; Tauri frontend renders the modal transitions.
- Priority: HIGH — directly addresses the #1 daily friction point for ADHD task-switchers. Low implementation complexity, high behavioral impact.
